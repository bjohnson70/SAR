Staff Preliminary Assessment is prominently labeled **PRELIMINARY — NOT AN OFFICIAL SECURITY DETERMINATION**. Reading repository documents does not establish cryptographic verification, trusted execution, official authorization, or applicability. Governed Assessment still requires trusted runtime context and fails closed without it. The preliminary path never silently escalates to governed mode.

Neither pathway supplies an authorized scoring methodology. Preliminary output may include evidence-grounded candidate controls/requirements only; it does not validate controls, create official findings, determine applicability, approve use, or authorize execution.
