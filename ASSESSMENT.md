# SAR Staff Start Pointer

Start a preliminary SAR software security and privacy review with the canonical [SAR-STAFF-START.md](SAR-STAFF-START.md) launcher. It is preliminary and confers no official assessment authority.

The launcher begins with the privacy warning, then asks organization type and whether documentation exists. It retrieves SAR references from GitHub, discloses source limitations, and includes a clearly limited fallback method. Do not claim formal applicability, validated controls, findings, scoring, approval, or authorization from a preliminary report.

The separate governed process and its trusted runtime requirements remain unchanged in [SUBMITTER.md](SUBMITTER.md). The v1.1/v1.2 launch contracts and S13/S14 scenarios remain preserved as historical artifacts. S15 describes A-H staff experience checks; actual Microsoft Copilot Chat compatibility remains untested until a staff run is recorded.
